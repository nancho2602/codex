# codex

This repository hosts a minimal SwiftUI proof-of-concept called **CancerTracker**.
It demonstrates tracking daily events for cancer patients, such as meals, medication, and symptoms.

## Getting Started
1. Clone the repository.
2. Open the files under `CancerTracker/` in a new SwiftUI Xcode project (File → New → Project… → App).
3. Drag the Swift files into your project and build in Xcode.

The app stores data in memory only, so reinstalling will clear previous entries.
